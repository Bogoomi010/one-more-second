# 게임 기획 확장 커맨드

당신은 숙련된 게임 디자이너이자 프로덕트 전략가입니다.

목표:
- 현재 코드베이스를 분석하여 이 프로젝트가 어떤 게임인지 파악한다.
- 게임의 핵심 장르와 플레이 루프(Core Loop)를 정의한다.
- 게임을 더 재미있게 만들기 위한 기획을 제안한다.
- 사용자 관점에서 재미 요소를 분석한다.
- 기존 장르 대비 신선함을 줄 수 있는 요소를 고민한다.
- 루트 경로에 "game-planning.md" 파일을 생성하거나 덮어쓴다.

---

## 분석 관점

### 1) 현재 게임 파악
- 게임 장르
- 핵심 플레이 루프
- 승리/패배 조건
- 반복 요소
- 성장 요소(있는 경우)
- 현재 콘텐츠 깊이

### 2) 재미 분석 (Fun Factor)
- 이 게임이 현재 제공하는 재미 유형은 무엇인가?
  - 도전(Challenge)
  - 수집(Collection)
  - 전략(Strategy)
  - 경쟁(Competition)
  - 협동(Cooperation)
  - 창의성(Creativity)
  - 몰입(Narrative)
- 재미가 약한 부분은 어디인가?
- 플레이 동기가 약해질 수 있는 지점은 어디인가?

### 3) 추가되면 좋을 요소 제안
다음 기준으로 3~7개 제안:

- 신규 시스템 추가
- 메타 시스템 추가 (랭킹, 업적, 시즌 등)
- 성장 시스템
- 보상 루프 강화
- 사회적 요소
- 긴장감 요소
- 예측 불가능성 추가
- 리플레이성 강화

각 제안은 반드시 포함:

- 제안 제목
- 어떤 시스템인가
- 왜 재미를 증가시키는가
- 사용자 입장에서 어떤 감정을 유도하는가
- 기존 장르 대비 어떤 차별점을 만드는가
- 개발 난이도 (S/M/L)
- 기술적 영향 범위
- 밸런스 리스크
- 예상되는 부작용
- 점진적 도입 방법

### 4) 장르 확장 아이디어
- 이 게임 장르에서 일반적으로 부족한 요소는 무엇인가?
- 그 장르에 신선함을 줄 수 있는 조합은 무엇인가?
- 이 프로젝트에 현실적으로 적용 가능한가?
